# Deployment Guide – Uhrenheld

Uhrenheld is deployed as a static PWA to **GitHub Pages** with automatic CI/CD.

## Deployment Overview

```
Branch Push → GitHub Actions → Tests & Build → Deploy to Pages
     ↓              ↓                ↓              ↓
  main branch   CI/CD pipeline   Production    https://bernhardmayr.github.io/uhrenheld/
```

## Pre-Deployment Checklist

Before pushing to `main`, ensure all checks pass:

### Local Verification
```bash
npm run lint          # No ESLint errors
npm run typecheck     # No TypeScript errors
npm test              # All 99 unit/component tests pass
npm run test:e2e      # All E2E tests pass (optional locally)
npm run build         # Production build succeeds
```

### Quality Gates

- [ ] No `any` types in TypeScript
- [ ] Accessibility: `prefers-reduced-motion` respected

## Automatic Deployment (main branch)

**Trigger**: Merge PR to `main`

**Process**:
1. GitHub Actions workflow runs (see `.github/workflows/`)
   - Lint check (`npm run lint`)
   - TypeScript check (`npm run typecheck`)
   - Unit/component tests (`npm test`)
   - E2E tests (`npm run test:e2e`)
   - Production build (`npm run build`)

2. If all checks pass:
   - Build output (`dist/`) is pushed to GitHub Pages
   - Service Worker registered for offline support
   - App live at: `https://bernhardmayr.github.io/uhrenheld/`

3. If any check fails:
   - Deployment is blocked
   - Error details in GitHub Actions logs
   - PR author notified

**Time**: ~3–5 minutes from push to live

## Manual Deployment (If Needed)

If GitHub Actions fails or you need to redeploy:

```bash
# 1. Verify local tests pass
npm run lint && npm run typecheck && npm test

# 2. Build production bundle
npm run build

# 3. Deploy to Pages (requires GitHub CLI)
gh workflow run deploy.yml --ref main
# OR
git push origin main  # Trigger CI/CD
```

## Rollback (If Needed)

If a deployed version has issues:

```bash
# 1. Revert the problematic commit
git revert <commit-hash>
git push origin main

# 2. GitHub Actions redeploys from the reverted commit
# App rolls back to previous stable version in ~5 minutes
```

## Monitoring & Support

### Check Deployment Status
```bash
# View GitHub Actions history
gh run list --repo bernhardmayr/Uhrenheld

# View latest deployment details
gh run view --repo bernhardmayr/Uhrenheld <run-id>
```

### Health Checks
1. **App loads**: https://bernhardmayr.github.io/uhrenheld/
2. **Service Worker active**: Open DevTools → Application → Service Workers
3. **Offline works**: DevTools → Network → Offline → Refresh
4. **Manifest valid**: DevTools → Application → Manifest (should show "Identity")

### Common Issues & Fixes

| Issue | Cause | Fix |
|-------|-------|-----|
| **Blank page** | Service Worker cache stale | Hard refresh (Ctrl+Shift+R) or clear cache |
| **404 on assets** | Base path mismatch | Check vite.config.ts base path |
| **E2E tests timeout** | Dev server slow | Ensure `npm run dev` is running |
| **Images not loading** | CDN blocked | Use local/bundled assets only |
| **Offline doesn't work** | SW not registered | Check browser console for registration errors |
